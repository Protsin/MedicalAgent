# 产品说明

## 目标用户

- 希望在就诊前整理症状的家庭用户。
- 不确定该挂哪个科室、是否需要当天就医的用户。
- 需要生成简洁就诊摘要的用户。

## 用户流程

1. 填写昵称、年龄、性别，可全部不提供。
2. 用自然语言描述症状、持续时间、严重程度和基础情况。
3. 系统返回安全级别、建议科室、下一步观察/就医建议和关键追问。
4. 若为急症，页面置顶红色警示，并保留“拨打120”入口。
5. 用户可复制对话摘要，就诊时提供给医生参考。

## 主要界面区域

- **左侧**：就诊人信息与历史会话。
- **中间**：对话流与输入框。
- **右侧**：当前安全级别、科室建议、模型状态和使用边界。

## 分诊策略

| 级别 | 含义 | 建议动作 |
|---|---|---|
| emergency | 疑似急症 | 立即拨打120或去最近急诊 |
| urgent | 高风险或需尽早评估 | 24小时内就医 |
| routine | 非急症但建议评估 | 预约门诊 |
| self_care | 描述轻微且无警示 | 1-3天观察，加重即就医 |
| info_needed | 信息不足 | 继续追问关键信息 |

## 未来增强

- 症状开始时间、体温、血压、疼痛评分的结构化输入。
- 多成员档案与医生审核模式。
- 就诊摘要 PDF 导出。
- 针对老年、儿童、孕产妇的专用问卷。
- 本地化和更多方言/语言支持。
